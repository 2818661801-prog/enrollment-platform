## 二、表结构

### 2.1 `classes` 特色班表

| 字段 | 类型 | 默认值 | 注释 |
|------|------|--------|------|
| `id` | INT | 自增 | 主键 |
| `name` | VARCHAR(200) | — | 班级全称 |
| `category` | VARCHAR(20) | — | 类别：经管类 / 理工类 |
| `period` | VARCHAR(50) | — | 报名时间段（主轮，如成电班第二轮） |
| `round` | TINYINT(1) | 0 | 0=无第二轮 1=第一轮 2=第二轮 |
| `round1_period` | VARCHAR(50) | NULL | 第一轮时间段（round=2时填写） |
| `quota` | INT | 0 | 名额上限，-1=不限 |
| `enrolled` | INT | 0 | 已录取人数 |
| `description` | TEXT | NULL | 班级说明 |
| `is_deleted` | TINYINT(1) | 0 | 软删除：0正常 1已删除 |

> **round 字段说明**
> - `round=0`：单轮报名，直接用 `period`
> - `round=1`：第一轮报名（逻辑同 round=0，历史兼容）
> - `round=2`：两轮报名；第一轮用 `round1_period`，第二轮用 `period`

### 2.2 `applications` 报名记录表

| 字段 | 类型 | 默认值 | 注释 |
|------|------|--------|------|
| `id` | BIGINT | 自增 | 主键 |
| `name` | VARCHAR(50) | — | 姓名 |
| `id_card` | VARCHAR(18) | — | 身份证号 |
| `id_card_masked` | VARCHAR(18) | NULL | 脱敏身份证（中间4位变*） |
| `gender` | VARCHAR(10) | — | 性别 |
| `phone` | VARCHAR(20) | — | 联系电话 |
| `has_physics` | VARCHAR(10) | — | 是否选考物理：是/否 |
| `has_english` | VARCHAR(10) | — | 是否选考英语：是/否（仅ACCA/CFA/智能财务班填） |
| `class_id` | INT | — | 关联 classes.id |
| `hd_sub_type` | VARCHAR(20) | NULL | 杭电班子类别：经管类/理工类（仅杭电班填） |
| `status` | TINYINT(1) | 1 | 1=已报名 0=已撤回 2=已录取 |
| `is_admitted` | TINYINT(1) | 0 | 是否已录取：0否 1是 |
| `notice_agreed` | TINYINT(1) | 0 | 是否同意报名须知：0否 1是 |
| `apply_time` | DATETIME | 当前时间 | 报名提交时间 |

> **status 状态机**
> - `1`（已报名）：正常状态，可撤回
> - `0`（已撤回）：学生主动撤回，软删除等效
> - `2`（已录取）：管理员批量录取后变更

### 2.3 `sys_config` 系统配置表

| 字段 | 类型 | 注释 |
|------|------|------|
| `id` | INT | 主键 |
| `cfg_key` | VARCHAR(50) UNIQUE | 配置键 |
| `cfg_value` | TEXT | 配置值（JSON格式） |
| `updated_at` | DATETIME | 最后修改时间 |
| `updated_by` | VARCHAR(50) | 最后修改人 |

**已使用配置键：**

| cfg_key | cfg_value 示例 | 说明 |
|---------|----------------|------|
| `notice` | `{"title":"报名须知","conditions":[...],"notices":[...]}` | 学生端弹窗内容 |
| `admin_phone` | `***REMOVED***` | 管理员登录手机号（目前未强制校验） |
