# 移动端 Footer 重设计方案

> 日期：2026-07-23
> 类型：前端 UI 改造
> 范围：仅移动端（≤768px），桌面端保持现状

---

## 1. 背景与目标

### 1.1 现状
- 现有 `AppFooter.vue` 移动端是 3 列压缩布局
- 联系方式 + 快速链接排版密集、信息层级不清晰
- 缺少交互反馈（电话号码无法直接复制）

### 1.2 目标
- 参照参考设计（千问代码 HTML）的"联系卡片"风格
- 在移动端提供更清晰的信息层级和更好的视觉体验
- 增加"点击复制"交互，方便学生快速保存联系方式
- **桌面端保持原 3 列布局不变**

---

## 2. 设计原则

| 原则 | 说明 |
|------|------|
| **增量改动** | 只改移动端 CSS + 模板，桌面端不受影响 |
| **主题色统一** | 用项目主色 `#337eff`（蓝）替代参考设计的金色 `#e7b94e` |
| **Logo 自带文字** | 不再单独渲染"杭州电子科技大学信息工程学院"标题文字，由 logo.png 自带的文字呈现 |
| **交互友好** | 联系方式点击复制 + toast 反馈 |

---

```

│   ─────────  ◇  ─────────   │  ← 装饰分割线（中间菱形点）

│   ▍ 联系方式                 │  ← 蓝色小标签
│   ┌─────────────────────┐  │
│   │ ☎ 招生办电话          │  │  ← 联系卡片行
│   │   0571-58619116      │  │

│   ▍ 快速链接                 │

│   02   招生网           →    │

│                             │
│   © 2026 杭州电子科技大学... │
│   [13279] [0095]            │

```

### 3.2 样式规格

| 元素 | 规格 |
|------|------|
| **背景** | `#1e293b`（保持现有深色） |
| **Logo 容器** | `display: flex; justify-content: center; padding: 16px 0 8px` |
| **Logo 尺寸** | `width: 140px; height: auto;`（移动端清晰可见 logo 内的文字） |
| **Logo 圆角** | `border-radius: 6px` |
| **地址条** | 字号 13px，图标 15px 邮编 chip 蓝色边框 |
| **装饰分割线** | 1px 渐变线 + 中央 7px 蓝色菱形点 |
| **联系卡片行** | 13px 行高 1.6，hover 蓝色边框高亮，点击后 0.3s 蓝色背景一闪 |
| **编号目录** | 蓝色编号 `font-size: 18px; font-style: italic`，hover 右移 4px |
| **底部 chip** | 邮编 chip 蓝色细边框 |

## 4. 交互设计

### 4.1 点击复制（联系方式）

```javascript
// 联系方式卡片行加 data-copy 属性
<div class="crow" data-copy="0571-58619116">
  <span class="ic">📞</span>
  <span class="lab">招生办电话</span>
  <span class="val mono">0571-58619116</span>
</div>

// 点击 → navigator.clipboard.writeText → 弹出 toast
```

**复制 fallback：** 不支持 `navigator.clipboard` 的浏览器（旧版 WebView）走 `document.execCommand('copy')`。

### 4.2 Toast 提示

| 字段 | 值 |
|------|------|
| 位置 | `bottom: 24px; left: 50%; transform: translateX(-50%)` |
| 样式 | 蓝底白字，圆角 8px，shadow |
| 显示时长 | 1.6s 后淡出 |
| 文本 | "已复制：xxx" |

### 4.3 Hover 效果（移动端保留给桌面/平板）

| 元素 | 效果 |
|------|------|
| 联系卡片行 | `transform: translateX(4px); border-color: #337eff;` |
| 快速链接 | `padding-left: 8px; color: #fff;` |

## 5. 改动文件

| 文件 | 改动 |
|------|------|
| `enroll-web/src/components/AppFooter.vue` | 模板加 `data-copy` 属性 + logo 居顶 + 编号目录；CSS 加移动端新样式 + 点击复制 JS |

## 7. 风险与补救

| 风险 | 等级 | 补救 |
|------|------|------|
| logo.png 自带文字在小尺寸看不清楚 | 🟡 中 | 固定 140px 宽度（主人确认 logo 自带学校名字） |
| 复制按钮在某些浏览器不工作 | 🟢 低 | fallback 到 `document.execCommand('copy')` |
| 桌面端被影响 | 🟢 低 | 用 `@media (max-width: 768px)` 严格隔离 |
| Toast 与现有 ElMessage z-index 冲突 | 🟢 低 | Toast 用 `z-index: 1000` 高于 ElMessage |
