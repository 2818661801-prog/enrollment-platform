# 重复报名问题排查与修复记录（2026-09-01）

## 一、问题现象

内网（低代码平台库 `smart_academic_affairs`）存在 10 名学生"一人多条审核中(status=1)"的重复报名记录，疑似脏数据。

## 二、排查过程

### 2.1 内网查重（确认假重复）

按"同一身份证/手机号存在多条 status∈{1,3}"查重，内网命中 **10 人**：

| 姓名 | 有效报名数 | 同班重复 |
|------|-----------|---------|
| 贾静萱 | ×5 | 🔴 班6×3 + 班4×2 |
| 黄琳茜 | ×2 | 🔴 班6×2 |
| 邵佳琪 | ×3 | 否 |
| 孟羿/许淡胭/陈诺颖/王浩如/林心蕾/胡镇杨/吕卓轩 | ×2 | 否 |

### 2.2 内外网对比（推翻"学生重复报名"假设）

| 维度 | 外网 enroll_db | 内网 smart_academic_affairs |
|------|---------------|---------------------------|
| 总记录 | 524 | 524 |
| source | 全 student（学生报名） | 全 sync（同步写入） |
| 审核中(1) | 412 | 433 |
| 已撤回(2) | 41 | 18 |
| 查重结果 | 空（无重复） | 10 人重复 |

**关键发现**：
1. 外网**查重为空** → 学生报名防重生效，学生报不出重复
2. 外网这些学生其实是"1 条审核中 + N 条已撤回"的正常轨迹（报班→撤回→报别的班）
3. 内网撤回只有 18 条 vs 外网 41 条 → **撤回状态没同步过来**，被同步成了审核中

### 2.3 根因定位（两处）

**Bug A（enroll-server 同步接口无防重）**：
`ApplicationService.syncFromLowCode()` 只按 `idCard+classId` 去重，不校验身份证/手机号全局唯一 → 同步新增时可能产生新重复。

**Bug B（低代码平台 NASL 状态同步覆盖 bug，真正导致假重复）**：
NASL `dataSynchronization()` 重建内网时：
```nasl
if (MapContains(statusMap, outerApp.id)) {
    status = MapGet(statusMap, outerApp.id)  // 无条件用内网旧值
}
```
内网旧值永远是 1（首次同步写入）→ **外网最新的撤回(2)被忽略**，永远同步不过来。

## 三、修复方案

### 3.1 修复 A：enroll-server 同步防重

`syncFromLowCode()` 新增双 Set + DB 查询兜底：
- 同身份证/手机号已有 `status∈{1,3}` 有效报名 → 跳过新增（返回 `skipped` 统计）
- 仅拦"新增且有效报名"，撤回(2)/未录取(4) 不拦（允许重报其他班）
- 已编译打包：`enroll-server/target/enroll-server-1.0.0.jar`

**实测 4 场景全过**：同批次拦截、跨批次 DB 兜底、未录取放行、手机号拦截。

### 3.2 修复 B：NASL 状态同步逻辑（根因）

修改前：
```nasl
if (MapContains(statusMap, outerApp.id)) {
    status = MapGet(statusMap, outerApp.id)
} else {
    status = Convert<Integer>(outerApp.status)
}
```

修改后：
```nasl
if (MapContains(statusMap, outerApp.id)) {
    status = MapGet(statusMap, outerApp.id)
    if (status != 3 && status != 4) {
        status = Convert<Integer>(outerApp.status)  // 1/2 用外网最新状态
    }
} else {
    status = Convert<Integer>(outerApp.status)
}
```

**规则**：外网管学生行为（1审核中/2撤回以外网为准），内网管管理员结果（3已录取/4未录取以内网为准）。

## 四、验证结果（全部通过）

1. ✅ 内网同身份证多条 1/3：**0 行**（原来 10 人）
2. ✅ 内网同手机号多条 1/3：**0 行**
3. ✅ 状态对齐：内网撤回 18→40 ≈ 外网 42；审核中 427 vs 外网 430（差 3 为同步后新报名）
4. ✅ 26 条 outer_id 对照：25 条全对齐，505 补同步成功（id=111186）
5. ✅ outer_id 完整性：0 条缺失
